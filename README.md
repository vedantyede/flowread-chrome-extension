# FlowRead Chrome Extension

Speed read any selected text on the web — right-click and go.

## Install (Chrome / Brave / Edge — Mac & Windows)

1. Open **chrome://extensions** in your browser
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `flowread-extension` folder
5. The FlowRead icon will appear in your toolbar

## Usage

### Right-click method (recommended)

1. Select any text on any webpage
2. Right-click → **⚡ Read with FlowRead**
3. A reader window opens instantly and starts reading

### Manual paste (toolbar popup)

1. Click the FlowRead icon in your Chrome toolbar
2. Paste text into the box
3. Click **Open Reader →**

## Keyboard shortcuts (in reader window)

| Key            | Action            |
|----------------|-------------------|
| `Space`        | Play / Pause      |
| `←` / `→`      | Skip ±10 words    |
| `↑` / `↓`      | Speed ±50 WPM     |
| `Escape`       | Back to text edit |
| `Ctrl/Cmd + R` | Restart           |

## Features

- RSVP word-by-word display with ORP (Optimal Recognition Point) highlighting
- Speed presets: 100–1000 WPM
- Word limit filter (50 / 100 / 250 / 500 / All)
- Smart punctuation pacing (longer pause on `.!?,;:`)
- Skip back/forward 10 words
- Remembers your WPM preference across sessions
- Works on Mac and Windows
- No account, no data collection, no internet required
